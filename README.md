Sistem Informasi Perpustakaan modern yang dibangun menggunakan teknologi **cutting-edge**. Project ini mengimplementasikan Laravel 13 dengan performa tinggi dan antarmuka pengguna yang reaktif.

---

## ✨ Fitur Utama

- 🔐 **Secure Authentication** – Sistem login & register menggunakan Laravel Breeze (React/Inertia).
- 🌓 **Dark Mode Ready** – UI adaptif yang nyaman di mata.
- 🐳 **Dockerized Environment** – Menggunakan Laravel Sail untuk lingkungan pengembangan yang konsisten.
- ⚡ **Vite Integration** – Kompilasi aset frontend super cepat.
- 📱 **Responsive Design** – Tampilan elegan di semua ukuran layar.

## 🛠️ Tech Stack

| Komponen | Teknologi |
| :--- | :--- |
| **Backend** | Laravel 13 (PHP 8.3) |
| **Frontend** | React.js (via Inertia.js) |
| **Styling** | Tailwind CSS |
| **Database** | MySQL |
| **Dev Environment** | Laravel Sail (Docker) |
| **Build Tool** | Vite |
